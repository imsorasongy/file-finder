# 파일찾기 (File Finder)

윈도우용 한글 지원 파일 검색 프로그램. 파일명·내용 검색 모두 지원하며 SQLite FTS5 기반 색인 검색으로 빠른 재조회가 가능합니다.

## 기능

- **파일명 검색** (부분일치, 대소문자 옵션)
- **확장자 필터** (여러 개 지정 가능)
- **파일 내용 검색** — 다음 형식 지원
  - 텍스트: `txt`, `md`, `csv`, `html`, `xml`, `py`, `js`, `ts`, `json`, `yaml` 등
  - 한글: `hwp` (PrvText + BodyText 추출)
  - 문서: `pdf`, `docx`, `pptx`, `xlsx`
- **색인 검색** (SQLite FTS5 + trigram) — 대규모 폴더를 수 ms에 검색
  - 증분 업데이트 (mtime 비교로 변경 파일만 재색인)
  - 전체 재색인
- **결과 조작** — 탐색기에서 열기, 파일 실행, 경로 복사, 컬럼 정렬
- 단축키: `Enter` 검색, `Esc` 중지, `Ctrl+F` 파일명 입력

## 요구사항

- Windows (Linux/macOS에서도 대부분 작동하나 `ctypes` 기반 숨김폴더 감지는 Windows 전용)
- Python 3.10 이상
- Tkinter (보통 Python 설치 시 포함)

## 설치

```bash
pip install -r requirements.txt
```

내용 검색용 라이브러리는 전부 선택 사항입니다 — 없으면 해당 형식만 건너뜀.

## 실행

```bash
python 파일찾기.pyw
```

또는 `.pyw` 파일을 탐색기에서 더블클릭 (콘솔 창 없이 GUI만 뜸).

## 색인 검색 사용법

1. 프로그램 실행 후 **색인 관리...** 버튼 클릭
2. 색인할 폴더 추가 (예: `C:\Users\사용자\Documents`)
3. **전체 재색인** 클릭 → 첫 빌드 대기 (폴더 크기에 따라 수분 ~ 수십 분)
4. 메인 창에서 **⚡ 색인으로 검색** 체크 후 검색

색인 DB는 `~/.파일찾기_색인.db`에 저장됩니다.

## 한국어 검색 규칙

- **3자 이상** 쿼리: FTS5 trigram으로 빠른 매치
- **1-2자** 쿼리: LIKE 폴백 (색인 DB 내 전체 스캔, 여전히 파일시스템보다 빠름)
